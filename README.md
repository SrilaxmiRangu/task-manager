 # Task Management System A full-stack task tracker with authentication, filtering, and analytics. ## Tech Stack - Frontend: React (Vite), React Router, Recharts, Axios - Backend: Node.js, Express - Database: MongoDB (Mongoose) - Auth: JWT, bcrypt ## Setup 1. Clone this repo 2. Backend: `cd backend && npm install` 3. Create a `.env` file in `backend/` with `PORT`, `MONGO_URI`, and `JWT_SECRET` 4. Run backend: `npm run dev` 5. Frontend: `cd frontend && npm install && npm run dev` 6. Open `http://localhost:5173` ## API Endpoints - POST /api/auth/signup - POST /api/auth/login - GET /api/tasks (supports ?status, ?priority, ?search, ?page, ?limit, ?sort) - POST /api/tasks - PUT /api/tasks/:id - DELETE /api/tasks/:id - PATCH /api/tasks/:id/complete - GET /api/tasks/analytics ## Design Decisions - JWT-based stateless authentication for simplicity and scalability - Compound MongoDB index on (userId, status) for fast filtered queries - Server-side pagination and filtering to avoid loading all tasks at once - Global Express error-handling middleware for consistent error responses
